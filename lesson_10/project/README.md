# Автотест оформления заказа в SauceDemo

E2E-тест полного пути покупки в интернет-магазине
[SauceDemo](https://www.saucedemo.com/) на Python + Selenium + pytest
с отчётами Allure.

## Описание проекта

Тест проверяет успешное оформление заказа:

1. Авторизация под пользователем `standard_user`.
2. Добавление трёх товаров в корзину.
3. Проверка содержимого корзины.
4. Заполнение данных покупателя на Checkout.
5. Проверка итоговой суммы: стоимость товаров плюс налог 8%.
